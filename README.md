# aDonut

A modern automation mod for Minecraft (Fabric) featuring **Auto Sell** and **Auto Drop** modules with a sleek, dark-purple glassmorphism interface.

## Supported Minecraft Versions

| Folder | Minecraft Version | Java Version | Mod Loader |
|---|---|---|---|
| `aDonut 26.x/` | Minecraft 26.1 - 26.3 | Java 25 / 26 | Fabric Loader >= 0.16.x |
| `aDonut 1.21.x/` | Minecraft 1.21 - 1.21.11 | Java 21 | Fabric Loader >= 0.15.x |

## Building from Source

### Minecraft 26.x:
```bash
cd "aDonut 26.x"
./gradlew build
```
The output `.jar` will be generated in `build/libs/`.

### Minecraft 1.21.x:
```bash
cd "aDonut 1.21.x"
./gradlew build
```
The output `.jar` will be generated in `build/libs/`.

## Features
- **Auto Sell:** Automatically opens `/sell` menu and sells inventory items based on custom selection.
- **Auto Drop:** Drops items swiftly into target chests/menus using custom slots.
- **Modern UI:** Elementa-inspired clean cyber-violet dark glass interface with full multi-language (i18n) support.
